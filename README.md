# Portfolio Architect

Web制作・コーディング案件を獲得するための、個人ポートフォリオサイトを作成してください。

【目的】

クラウドワークス、ランサーズ、ココナラなどでWeb制作案件に応募する際に、クライアントへ見せるポートフォリオとして使用します。

「この人なら安心してWeb制作を任せられそう」と感じてもらえる、プロフェッショナルで信頼感のあるデザインにしてください。

【デザイン】

・シンプルで洗練されたモダンなデザイン

・白、黒、グレーをベースにする

・アクセントカラーを1色使用

・余白を広めに取り、高級感のあるデザイン

・派手すぎない

・Web制作会社やフリーランスエンジニアのような雰囲気

・PC、タブレット、スマートフォン完全レスポンシブ対応

・スクロール時に自然なフェードインアニメーション

・ボタンやカードには上品なホバーアニメーション

・日本語サイト

【サイト構成】

1. HERO / TOP

最初に大きく

「Webサイト制作で、

あなたの想いをカタチに。」

というキャッチコピーを表示。

その下に

「Web Design / Coding / Responsive」

と表示。

さらに

「制作実績を見る」

「お問い合わせ」

の2つのボタンを配置。

2. ABOUT

見出し：

「ABOUT」

内容：

Web制作・フロントエンド開発を行っています。

HTML / CSS / JavaScriptを中心に、ユーザーにとって見やすく使いやすいWebサイト制作を心がけています。

お客様のご要望を丁寧にヒアリングし、最後まで責任を持って対応いたします。

※顔写真を後から追加できるスペースを用意してください。

3. SKILLS

HTML

CSS

JavaScript

Responsive Design

Git / GitHub

それぞれカード形式で表示。

習熟度を「○%」のように表示しないでください。

4. SERVICE

以下のサービスをカード形式で表示。

「LP制作」

デザインをもとにランディングページをコーディングします。

「Webサイト制作」

企業サイト・店舗サイト・個人サイトなどのWebサイト制作に対応します。

「レスポンシブ対応」

PC・タブレット・スマートフォンで最適に表示されるサイトを制作します。

「Webサイト修正」

HTML / CSS / JavaScriptを使用した既存サイトの修正・調整に対応します。

5. WORKS

制作実績を6件程度掲載できるカードレイアウトを作成してください。

各カードには

・サイトの画像

・サイト名

・使用技術

・簡単な説明

・「詳しく見る」ボタン

を配置。

現時点では仮の作品を入れておき、後から自分の作品に簡単に差し替えられる構造にしてください。

6. FLOW

お問い合わせから納品までの流れを表示。

01 お問い合わせ

02 ヒアリング

03 制作

04 確認・修正

05 納品

初めてWeb制作を依頼する人でも安心できる説明を付けてください。

7. CONTACT

「Webサイト制作・修正のご相談はこちら」

というメッセージを表示。

お問い合わせボタンを配置してください。

8. FOOTER

名前

ナビゲーション

Copyright

を表示。

【重要】

・SEOを意識したHTML構造にする

・アクセシビリティを考慮する

・コードは読みやすく整理する

・後からCursorで編集しやすい構成にする

・不要に複雑な機能やライブラリを追加しない

・スマートフォンで見たときも非常に綺麗なデザインにする

・架空の経歴や実績、案件経験は記載しない

・まだ実案件ではない制作物について「クライアントワーク」と誤解される表現を使わない

まずはサイト全体を完成させてください。

細かい文章、画像、制作実績などは完成後に変更します。
